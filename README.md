# 通用单元刚度矩阵多智能体工作流

本项目用于把有限元单元的实现矩阵与可信求解器参考矩阵进行可复验比较。公共层负责样本登记、数据集隔离、误差计算、测试、补丁门禁和多智能体编排；具体单元负责从样本 JSON 生成自己的刚度矩阵。

当前内置示例是 Abaqus S4：4 个节点、每节点 6 个自由度、`24 x 24` 矩阵。框架也支持其他方阵尺寸，但接入新单元时必须提供对应的矩阵程序、参考样本和测试。

当前 `sample_001` 的 Frobenius 相对误差为 `0.0410265`。工程闭环和测试已经通过，但多样本误差尚未达到 `1%`，因此不能表述为数值算法已最终验收。

## 核心目录

```text
stiffness_agent/        命令行、项目配置、验证逻辑和提示词
scripts/                多智能体编排和 Abaqus 工具
data/                   样本、参考矩阵、实现矩阵和数据集
src/、include/          当前 S4 C++ 实现
tests/                  Python 与 Catch2 测试
docs/                   用户手册、技术说明和验证结果
build/                  可重新生成的本地输出，不提交
```

当前项目入口为 `stiffness_agent/config/project.json`，非 S4 配置示例为 `stiffness_agent/config/project.example.json`。

## 安全规则

- 不提交 `.env`、密钥或令牌；
- 不允许模型生成或修改可信参考矩阵；
- 新样本必须记录真实求解器或外部参考来源；
- `train`、`validation` 和 `test` 不得重叠；
- 最终测试集必须通过哈希锁校验；
- `build/` 和 `build/workflow/` 是本地生成内容。
