# 壳单元刚度矩阵当前方案

更新日期：2026-09-06

## 1. 项目目标

本项目提供一条可复验的单元刚度矩阵工作流：读取样本元数据，调用 C++ 实现生成单元矩阵，与真实求解器参考矩阵比较，并由 Python、Catch2 和确定性门禁给出验证结果。

当前内置实现是 Abaqus S4 示例：四节点、每节点 6 个自由度，矩阵尺寸为 `24 x 24`。工作流的数据模型和命令层支持通过适配器接入其他单元与其他方阵尺寸，但新增单元仍需提供对应的 C++ 计算实现、参考数据和测试。

## 2. 已固定的 S4 口径

- 单元类型：Abaqus `S4`。
- 节点顺序：`1, 2, 3, 4`，按单元法向观察为逆时针。
- 每节点自由度顺序：`ux, uy, uz, rx, ry, rz`。
- 材料：各向同性线弹性，参数为 `E` 和 `nu`。
- 截面：均匀厚度壳截面。
- 参考矩阵：必须来自真实 Abaqus `*MATRIX GENERATE` 导出，不得用 C++ 结果替代。
- 主比较指标：Frobenius 相对误差；同时记录最大绝对误差、最大逐项相对误差和对称性误差。

不同软件的横向剪切、钻转刚度、局部坐标和稳定化处理并不完全相同，因此 ANSYS SHELL181 与旧 Shell203 资料只作为理论参考，Abaqus S4 才是当前数值对齐基准。

## 3. C++ 计算路线

当前实现位于 `include/fem/s4/` 和 `src/fem/s4/`，核心过程为：

1. 从四个节点建立单元局部正交坐标系。
2. 将节点坐标投影到局部中面。
3. 在 `2 x 2` Gauss 点上组装膜、弯曲和横向剪切刚度。
4. 使用罚刚度稳定每节点第六个钻转自由度。
5. 将局部 `24 x 24` 矩阵变换回全局自由度坐标。
6. 输出矩阵并由独立比较程序计算误差。

物理形式以 `K = integral(B^T D B)` 为基础。非共面四边形采用单元中心平均平面近似；这也是畸变样本误差通常高于规则平面样本的重要来源。

## 4. 数据与验证链路

参考数据保存在 `data/reference/abaqus/`：

- `input_decks/`：可复现建模口径的 Abaqus 输入文件；
- `raw_matrices/`：Abaqus 原始 `.mtx`；
- `matrices/`：转换后的方阵 CSV；
- `metadata/`：节点、材料、自由度、来源和日志字段；
- `logs/`：证明真实作业完成的必要日志。

实现矩阵保存在 `data/implementation/`。数据集清单决定样本属于 `train`、`validation` 或 `test`；开发验证不得读取锁定的 `test` 数据。

验证驱动会配置并编译 C++，运行 Catch2，重新生成实现矩阵，再计算参考矩阵与实现矩阵的误差。批量验证只读取当前允许的划分，并把可再生成结果写入 `build/verification/`。具体操作命令只在用户手册中维护。

## 5. 多智能体边界

在线智能体只提出计划、理论假设、受限补丁和评审建议。以下事实始终由本地程序决定：

- 补丁是否只修改允许的实现文件；
- C++ 是否编译成功；
- Catch2 和 Python 测试是否通过；
- 参考矩阵是否来自登记的数据集；
- 候选误差是否改善且没有破坏验证集；
- 候选代码最终保留还是回退。

提示词、角色和产物位置见 `docs/agents/多智能体角色定义.md`。在线运行记录统一保存在被 Git 忽略的 `build/workflow/`，不写入用户文档。

## 6. 接入其他单元

接入非 S4 或非 `24 x 24` 矩阵时，需要同时完成：

1. 在项目配置中声明单元类型、矩阵尺寸、实现命令和允许修改路径。
2. 提供新单元的 C++ 计算入口或命令适配器。
3. 创建带明确自由度顺序和来源信息的参考样本元数据。
4. 登记数据集划分并设置相应验收门槛。
5. 增加覆盖矩阵尺寸、有限性、对称性、异常输入和数值对标的测试。

这些是公共框架对新单元的技术契约，用户操作步骤只在 `docs/用户手册.md` 中维护。

## 7. 当前验收状态

工程链路、真实 Abaqus S4 数据、批量数据集验证和多智能体受限迭代均已接通。当前实现尚未在全部样本上达到 `1%` 的目标，因此文档只能报告“流程与测试通过”，不能表述为“S4 数值算法已验收”。最新可复验指标以 `docs/verification/` 中的报告为准。
