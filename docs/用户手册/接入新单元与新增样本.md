# 接入新单元与新增样本

本页区分两种任务：给当前单元增加样本，以及接入一套新的单元实现。

## 只增加一个样本

以当前 S4 项目为例，一个新样本需要：

1. 新的 Abaqus 输入文件；
2. 真实导出的原始矩阵和证据日志；
3. 转换后的参考矩阵 CSV；
4. 样本元数据 JSON；
5. 数据集登记；
6. 重新生成的实现矩阵和验证报告。

推荐顺序：

```text
设计几何与材料
-> 运行可信求解器
-> 导出原始矩阵
-> 转换并校验 CSV
-> 填写元数据
-> register-sample
-> verify
-> verify-dataset --development
```

登记前先确认参考矩阵不是由待验证实现生成的，也没有覆盖已有样本。

```bash
python -m stiffness_agent register-sample \
  --meta data/reference/abaqus/metadata/<sample_id>.json \
  --split train
```

`--split` 可选 `train`、`validation`、`test`。登记 `test` 会重建测试集哈希锁。

## 接入新单元前的清单

先明确以下契约：

- 单元名称和节点数；
- 每节点自由度及全矩阵自由度顺序；
- 刚度矩阵尺寸；
- 几何、材料、截面和积分参数；
- 可信参考矩阵的生成方法；
- 矩阵计算程序读取哪些样本参数；
- 矩阵计算程序输出的 CSV 路径和尺寸；
- 该单元需要通过哪些数值测试。

## 推荐目录

新单元推荐按单元归档实现和数据，避免与 S4 文件混在一起：

```text
elements/beam2/
├── include/                 梁单元公开接口
├── src/                     梁单元实现和 CLI
└── tests/                   梁单元测试

data/beam2/
├── meta/                    样本元数据
├── raw/                     求解器原始导出
├── evidence/                作业日志
├── reference/               可信参考矩阵 CSV
└── actual/                  实现矩阵 CSV
```

这是推荐布局，不是框架硬编码要求。现有 S4 保留历史目录 `include/fem/s4/`、`src/fem/s4/`、`tests/` 和 `data/reference/abaqus/`。

## 完整示例：接入一个 6 x 6 梁单元

假设是二维两节点梁，每节点自由度为 `ux、uy、rz`，总矩阵为 `6 x 6`。

本例使用 Python 计算梁刚度，不需要先写 C++ 或 CMake。完成后，验证命令实际做的事情是：

```text
读取样本 JSON
-> 运行 Python 梁单元程序
-> 程序写出 6 x 6 实现矩阵
-> 工作流读取 Abaqus 参考矩阵
-> 比较两个矩阵并生成报告
```

### 1. 确认项目参数

在 `stiffness_agent/config/project.json` 中确认以下参数。下面只列出更换单元时需要理解的主要输入，不展示内部运行配置：

```json
{
  "schema_version": 1,
  "project_id": "beam2-stiffness",
  "element_type": "BEAM2",
  "matrix_dimensions": [6, 6],
  "node_count": 2,
  "dof_labels_per_node": ["ux", "uy", "rz"],
  "diagnostic_groups": {
    "axial": ["ux"],
    "bending": ["uy", "rz"]
  },
  "dataset": "data/datasets/beam2.json",
  "primary_sample": "data/beam2/metadata/train_001.json",
  "reference_generation_methods": ["matrix_generate"],
  "agent": {
    "allowed_patch_paths": ["elements/beam2/generate_matrix.py"],
    "test_paths": [],
    "experiment_classes": ["formulation", "integration", "dof_mapping"]
  },
  "acceptance": {
    "target_error": 0.01
  }
}
```

### 2. 创建样本元数据

`data/beam2/metadata/train_001.json`：

```json
{
  "sample_id": "beam2_train_001",
  "element_type": "BEAM2",
  "parameters": {
    "nodes": [[0.0, 0.0], [1.0, 0.0]],
    "E": 210000000000.0,
    "area": 0.01,
    "inertia": 8.333333333e-6,
    "dof_order_per_node": ["ux", "uy", "rz"]
  },
  "reference_matrix_source": {
    "status": "real_abaqus_export",
    "solver": "Abaqus 2024",
    "job": "beam2_train_001",
    "method": "MATRIX GENERATE"
  },
  "reference_matrix": "data/beam2/reference/train_001.csv",
  "implementation_matrix": "data/beam2/implementation/train_001.csv"
}
```

`parameters` 是传给梁单元计算程序的输入。公共验证代码不理解 `E`、`area` 或 `inertia`，这些字段由下面的 `generate_matrix.py` 读取。

### 3. 准备参考矩阵

验证前必须已经存在：

- `data/beam2/reference/train_001.csv`：由 Abaqus 或其他可信求解器生成的 `6 x 6` 参考矩阵。

不需要手工创建 `data/beam2/implementation/train_001.csv`。下一步的 Python 程序会自动生成它。参考矩阵不能由这个 Python 程序生成，否则就变成了拿程序和自己比较。

### 4. 编写矩阵计算程序

创建 `elements/beam2/generate_matrix.py`：

```python
import csv
import json
import math
import sys
from pathlib import Path


ROOT = Path(__file__).resolve().parents[2]


def multiply(left, right):
    rows = len(left)
    cols = len(right[0])
    shared = len(right)
    return [
        [sum(left[i][k] * right[k][j] for k in range(shared)) for j in range(cols)]
        for i in range(rows)
    ]


def transpose(matrix):
    return [list(row) for row in zip(*matrix)]


sample_path = Path(sys.argv[1])
if not sample_path.is_absolute():
    sample_path = ROOT / sample_path

sample = json.loads(sample_path.read_text(encoding="utf-8"))
parameters = sample["parameters"]
(x1, y1), (x2, y2) = parameters["nodes"]
dx = x2 - x1
dy = y2 - y1
length = math.hypot(dx, dy)
if length <= 0.0:
    raise ValueError("梁长度必须大于 0")

young = float(parameters["E"])
area = float(parameters["area"])
inertia = float(parameters["inertia"])

axial = young * area / length
bending_1 = 12.0 * young * inertia / length**3
bending_2 = 6.0 * young * inertia / length**2
bending_3 = 4.0 * young * inertia / length
bending_4 = 2.0 * young * inertia / length

# 局部自由度顺序：ux1, uy1, rz1, ux2, uy2, rz2
local = [
    [axial, 0.0, 0.0, -axial, 0.0, 0.0],
    [0.0, bending_1, bending_2, 0.0, -bending_1, bending_2],
    [0.0, bending_2, bending_3, 0.0, -bending_2, bending_4],
    [-axial, 0.0, 0.0, axial, 0.0, 0.0],
    [0.0, -bending_1, -bending_2, 0.0, bending_1, -bending_2],
    [0.0, bending_2, bending_4, 0.0, -bending_2, bending_3],
]

cosine = dx / length
sine = dy / length
transform = [[0.0] * 6 for _ in range(6)]
for base in (0, 3):
    transform[base][base] = cosine
    transform[base][base + 1] = sine
    transform[base + 1][base] = -sine
    transform[base + 1][base + 1] = cosine
    transform[base + 2][base + 2] = 1.0

global_matrix = multiply(transpose(transform), multiply(local, transform))
output_path = ROOT / sample["implementation_matrix"]
output_path.parent.mkdir(parents=True, exist_ok=True)
with output_path.open("w", newline="", encoding="utf-8") as handle:
    csv.writer(handle).writerows(global_matrix)

print(f"wrote {output_path}")
```

这个程序可以先脱离工作流单独测试：

```bash
python elements/beam2/generate_matrix.py data/beam2/metadata/train_001.json
```

成功后应生成 `data/beam2/implementation/train_001.csv`，文件有 6 行，每行 6 个数。

### 5. 确认程序的输入和输出

矩阵计算程序只需要遵守下面的文件约定：

| 项目 | 内容 |
| --- | --- |
| 输入 | 一个样本元数据 JSON 文件的路径 |
| 输入内容 | 节点、材料、截面、自由度顺序等计算参数 |
| 输出位置 | 样本 JSON 中 `implementation_matrix` 指定的路径 |
| 输出格式 | 无表头、逗号分隔的方阵 CSV |
| 输出尺寸 | 节点数乘以每节点自由度数，本例为 `6 x 6` |

本例可以直接运行：

```bash
python elements/beam2/generate_matrix.py data/beam2/metadata/train_001.json
```

运行前，`data/beam2/metadata/train_001.json` 是输入。运行后，`data/beam2/implementation/train_001.csv` 是输出。工作流随后读取这个输出和 `data/beam2/reference/train_001.csv`，比较两个矩阵并生成报告。

如何让项目自动调用该程序属于项目维护配置，普通用户不需要在第一次使用时理解。

### 6. 创建数据集

`data/datasets/beam2.json`：

```json
{
  "schema_version": 2,
  "project_id": "beam2-stiffness",
  "train": ["data/beam2/metadata/train_001.json"],
  "validation": [],
  "test": []
}
```

### 7. 验证

```bash
python -m stiffness_agent validate-project
python -m stiffness_agent verify --sample data/beam2/metadata/train_001.json --report build/verification/beam2-train-001.md
python -m stiffness_agent verify-dataset --development
```

## 完成接入后会得到什么

| 产物 | 来源 |
| --- | --- |
| `data/beam2/implementation/*.csv` | 用户提供的矩阵计算程序 |
| 单样本报告 | `verify` |
| `build/verification/dataset-results.json` | `verify-dataset` |
| 编译与测试输出 | 单元程序自己的构建和测试过程 |
| 规划和迭代记录 | 可选的 `replan`、`run` |

接入成功只表示流程可运行；是否达到数值目标，以独立测试集和验收阈值为准。
