# 文档目录

本目录是通用单元矩阵工作流及当前 S4 示例的技术文档入口。

## 用户手册

- `用户手册.md`：按任务选择入口，并给出标准操作主流程。
- `用户手册/快速开始.md`：第一次运行现有 S4 验证。
- `用户手册/接入新单元与新增样本.md`：新增样本或接入非 S4、非 `24 x 24` 单元。
- `用户手册/文件与字段参考.md`：目录、配置字段、样本字段、命令和文件生命周期速查。
- `用户手册/项目可运行检查.md`：检查项目是否具备运行条件。
- `用户手册/架构与协同.md`：适配器、数据集和多智能体协同的设计说明。

用户文档采用“快速开始、操作指南、参考、原理说明”分层。可复验的数值结论仍放在 `verification/`，不与入门步骤混写。

## 需求与理论文档

- `requirements/壳单元刚度矩阵技术路线.md`：整体技术路线。
- `requirements/壳单元刚度矩阵当前方案.md`：当前实施方案。
- `requirements/Abaqus-S4理论基线.md`：S4 理论口径。

## 智能体文档

- `agents/多智能体角色定义.md`：角色定义。

## Abaqus 文档

- `abaqus/导出S4刚度矩阵.md`：S4 刚度矩阵导出流程。

## 验证文档

- `verification/样本001验证报告.md`：主样本数值验证报告。
- `verification/S4多样本Abaqus验证报告.md`：当前多样本验证汇总。

## 维护规则

- 每轮可验证进展同步当前验证报告。
- 讨论项标记“待确认”，不能写成已完成。
- 数值达到目标前不能表述为“算法验收通过”。
